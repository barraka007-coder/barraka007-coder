### Na čem pracuji

**CzechMyNet — Your network. Your rules.**

Vlastní projekt síťového monitoru a nástroje pro ochranu soukromí ve Windows. Cílem je ukázat, které aplikace komunikují po síti, zpřístupnit přehled o spojení a později nabídnout i vlastní pravidla blokování — bez zásahů do konfigurace Windows Firewallu.

- **Hotovo:** základní sledování síťových endpointů a spojení; první grafické rozhraní.
- **Ve vývoji:** pokročilejší monitoring, historie a přehled příchozích pokusů.
- **Plánováno:** samostatné blokování síťové komunikace.
- **Principy:** lokální zpracování, žádná telemetrie, nízká systémová zátěž.

[Veřejná prezentace CzechMyNet](https://github.com/barraka007-coder/CzechMyNet-Public) *(projekt zatím není dostupný ke stažení)*

Kromě toho experimentuji s AI asistovaným vývojem, zpracováním tržních dat a vlastními automatizačními nástroji.

### Current project

**CzechMyNet — Your network. Your rules.**

An independent Windows network monitoring and privacy project. The goal is to make network activity understandable, show which applications are communicating and eventually provide independent connection-blocking rules without modifying Windows Firewall settings.

- **Working:** basic monitoring of network endpoints and connections; an initial graphical interface.
- **In development:** more advanced monitoring, history and visibility into incoming connection attempts.
- **Planned:** independent network traffic blocking.
- **Principles:** local processing, no telemetry and low resource usage.

[CzechMyNet public project page](https://github.com/barraka007-coder/CzechMyNet-Public) *(not available for download yet)*
